# To-Do List

A browser-based list for capturing things to do and ticking them off. People sign up and log in before using it.

## Language

**User**:
A person who uses the app.
_Avoid_: Customer, member

**Account**:
A user's registered identity: username, name, email and password. Username and email each belong to one account only.
_Avoid_: Profile, login (as a noun)

**Sign up**:
Creating a new account.
_Avoid_: Register (in UI text), create user, enrol

**Log in**:
Proving who you are with your username and password, which starts a session.
_Avoid_: Sign in, authenticate (in UI text)

**Session**:
The time during which a user is logged in, from log in until log out or expiry.
_Avoid_: Token, login

**Log out**:
Ending the current session.
_Avoid_: Sign out, log off

**Task**:
One thing the user intends to do, identified by its title.
_Avoid_: Todo, item, note

**Active task**:
A task that has not been completed yet.
_Avoid_: Open, pending, incomplete

**Completed task**:
A task the user has marked as done.
_Avoid_: Done, finished, checked

**Time spent**:
The total time the user has recorded on a task, from manual minutes and the timer.
_Avoid_: Duration, hours logged, elapsed

**Timer**:
A start/stop clock on a task; stopping adds the elapsed time to its time spent.
_Avoid_: Stopwatch, tracker

**Filter**:
The choice of which tasks are shown: All, Active, or Completed.
_Avoid_: View, tab

**Clear completed**:
Removing every completed task at once.
_Avoid_: Archive, purge

**Mark all complete**:
Making every task completed, or every task active again if all are already completed.
_Avoid_: Select all, complete all
